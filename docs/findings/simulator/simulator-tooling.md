# Simulator package, tooling and validation status (updated 2026-11-12 for `SIM_STABLE_V2`)

Code: local `hf_ml/SIM_STABLE_V2/` (modular refactor of `SIM_STABLE`, bit-exact in output across all 28 dump-backed sessions and combat replays). Data: local `hf_ml/data/sim_runs*/*.hftm` and `Modloader/logs/*.hftm`.

## Package layout (`SIM_STABLE_V2/sim/hfsim/`)
* **Core flight & physics:** `paths.py` (config/session discovery), `units.py` (`S = 0.05`, key bitmasks, float32 `servo_err` wrap with exact `+-pi` tie behaviour), `seria.py` (`.seria` + `OL.seria` + `parts.seria` loader and `BreakUpFrame` slot graph), `physics.py` (`ShipBody`, engine `shiftB`, folded landing legs on limited revolute hinges + `10 Hz` distance struts, `frame_bbox`), `thermal.py` (engine dose, downhill slot conduction, `+1.0/tick` burn self-heat), `stabiliser.py` (`creatureLogic` case 200 hull attitude stabiliser), `flight.py` (`Flight`, realistic drag + code stabiliser enabled by default, `remove_part`, `extinguish`), `landscape.py` (float32 `generateCityLandscape`), `env.py` (`FlightEnv`).
* **AI, combat, I/O, validation & viz:** `ai/{avoidance,steering,pilot}.py` (`AiPilot` and log-assisted `ClosedAI`), `combat/{ammo,shells,damage,stubs}.py` (verified 1.163 ammo table, `0.05/s`-damped `Shell` + `swept_hit`, 360-bucket `blast()`, plus `GunMountStub` / `check_ship_kill_rules` / `CombatArenaStub` previews), `io/{hftm,logs,dumpship,session}.py`, `validation/{state,rig,diagnostics,metrics,ai_check}.py`, `viz/{recorder,simview,explorer,diff_report,battle_report}.py`, and CLI wrappers `sim/{simview,simdiff,simreport,simmetrics,hftm}`.

## Key tooling and model facts
* **Ship from the dump (`hfsim/io/dumpship.py`):** rebuilds the flown ship from `hf_ally_ship_<id>_<n>.seria` (root Frame + tree), `_extra.seria` (world-space jointed parts) and sim.39+ `simparts` `J` rows (`j_a_id`/`j_b_id`, shifts, angle limits, motor, length). Unfolds dumped standing-pose legs back to the design `angle = 0` convention so `leg_fold` places them on the in-flight limit, and drops physics-free `ANTENNA_PART` markers and their extra weld joints. Reproduces library `oid` multisets, `Frame_RecomputeBounds` (`+0x218/+0x21c`), COM and inertia to four digits.
* **Design variants:** ships with identical part lists can differ in engine bank spasm codes (`Lightning`, `Lightning_Stock`, `Lightning_save`); for pre-dump sessions `pick_design` selects the variant whose L/R banks match logged two-angle command steps.
* **Key & command timing (`hfsim/validation/rig.py`):** 30 Hz `P`-row key bits have `+-33 ms` edge jitter; when 50 Hz `EA` hook records are present, keys are decoded from the `EA` bank angles (`DECODE_KEYS`), with 1-tick command/angle lag (`ANGLE_REC_LAG = 1`, `KEY_LAG = 1`, `STRENGTH_REC_LAG = 1`) matching the frame integration boundary.
* **Conduction & FSS (`hfsim/thermal.py`, `flight.py`):** once `Part_ExtinguishNearbyParts` (`0x140033800`) was decoded to reset **all** parts in `+0x1330` within `30.0` design units (including neighbour trusses) to `T = 100` and `Body_BurnUpdate` was confirmed to run twice per tick (`0.8 + 0.2 = 1.0`), the decoded `onward_scale = 1.0` replaced the old `0.8` fit.
* **Validation tools:** `./sim/simdiff <hftm> [--ship N] [--closed]` (open-loop + 3 s re-seeded windows + force/mask/temperature ablations + interactive HTML explorer), `./sim/simmetrics <ids...>` (1 s and 3 s continuous error medians/p90s + overheat trip lateness), `./sim/simreport <hftm>` (multi-ship battle map with shared cursor), `./sim/simview` (static/scripted/log hull viewer). Windows within `120 u` of terrain are excluded by default (mid-air combat scope).
* **Measured fidelity across 28 dump-backed sessions (`1,935` 1 s windows, `637` 3 s windows, `248` overheat lockouts):**
  * **1 s windows:** hull angle median `0.041 deg` (p75 `0.45`, p90 `2.96`), spin median `0.0009 rad/s`, velocity median `0.10 u/s` (p90 `1.28`), position median `0.081 u` (p90 `0.83`), engine temperature median `0.48 deg`.
  * **3 s windows:** hull angle median `0.114 deg` (p75 `1.44`), spin median `0.0016 rad/s`, velocity median `0.42 u/s` (p90 `2.97`), position median `0.63 u` (p90 `5.04`), engine temperature median `1.05 deg`.
  * **Overheat lockouts:** `246 / 248` (`99.2 %`) reproduced within `1 s`; onset lateness median `+0.000 s` (`p10 = -0.020 s`, `p90 = +0.020 s`, i.e. `+-1` tick).
  * **Remaining tail:** concentrated in fast-spin (`5–11 rad/s`) 2-engine tumbling flights (`1792666463`, `1792751383`, `1792753787`), where float32 C++ Box2D vs float64 pybox2d and single-engine idle-bank flips accumulate over multi-second windows.
